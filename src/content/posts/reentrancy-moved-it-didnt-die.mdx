The classic single-function reentrancy is easy to spot now. The one that still bites is cross-function and read-only reentrancy: a view function returns stale state while another contract is mid-call.

My rule: update state before any external call, and treat every view another protocol might read as part of your attack surface.

```solidity
function withdraw(uint amt) external {
    balances[msg.sender] -= amt;   // effects first
    (bool ok,) = msg.sender.call{value: amt}("");
    require(ok);
}
```
