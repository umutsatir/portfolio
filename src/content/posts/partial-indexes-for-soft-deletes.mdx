excerpt: "Let a soft-deleted row stop blocking a new one with the same email."
---

Soft-deleted rows should not block a new row with the same email. A partial unique index does exactly that.

```sql
CREATE UNIQUE INDEX users_email_live
ON users (email)
WHERE deleted_at IS NULL;
```
